# Система отказоустойчивого инференса для KolektorSDD2

Проект решает задачу бинарной классификации изображений `normal / defect` на датасете `KolektorSDD2`.

Текущая схема:
- основная модель: `ResNet50`
- резервная модель: `MobileNetV2`
- инференс выполняется на `PyTorch` с поддержкой `CUDA`

## Ноутбук

В ноутбуке показаны:

- загрузка датасета и EDA
- дисбаланс классов
- предобработка и аугментации
- метрики до и после балансировки
- итоговые таблицы `pandas`
- monitoring и симуляция деградации входа
- fallback-инференс
- замер времени обработки одного изображения
